VENGADESH MILK SALES - APK BUILD PACKAGE

மொபைலில் APK உருவாக்க:
1. இந்த ZIP-ஐ Extract செய்யவும்.
2. GitHub கணக்கில் புதிய repository உருவாக்கவும்.
3. Extract செய்துள்ள கோப்புகளையும் folders-ஐயும் repository-க்கு upload செய்யவும். .github folder-ஐயும் சேர்க்கவும்.
4. Repository-ல் Actions tab திறக்கவும்.
5. Build Android APK workflow தேர்வு செய்து Run workflow அழுத்தவும்.
6. Build முடிந்ததும் workflow run-ஐத் திறந்து Artifacts பகுதியில் Vengadesh-Milk-Sales-APK பதிவிறக்கவும்.
7. ZIP artifact-ஐ Extract செய்து app-debug.apk-ஐத் திறந்து Install செய்யவும். Android கேட்டால் அந்த browser/files app-க்கு Install unknown apps அனுமதி அளிக்கவும்.

குறிப்பு: இது Debug APK. தனிப்பட்ட மொபைல் பயன்பாட்டிற்கானது. இந்த Android wrapper-ல் App உள்ளடக்கம் offline-ஆக assets-லிருந்து திறக்கும். தரவு WebView local storage-ல் சேமிக்கப்படும்; App data clear/uninstall செய்தால் தரவு அழியலாம். Backup/export வசதியைப் பயன்படுத்தவும்.
